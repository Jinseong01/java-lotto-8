# java-lotto-precourse

## 기능 목록

- ### 입출력 기능
    - [x] `구입금액을 입력해 주세요.`의 형식으로 안내 메시지를 출력한다.
    - [x] 사용자로부터 구입금액 문자열을 입력받는다.
    - [x] `N개를 구매했습니다.`의 형식으로 발행된 로또의 개수를 출력한다.
    - [x] `[n1, n2, n3, n4, n5, n6]`의 형식으로 발행된 로또 N개의 번호를 출력한다.
    - [x] `당첨 번호를 입력해 주세요.`의 형식으로 안내 메시지를 출력한다.
    - [x] 사용자로부터 쉼표(,)로 구분된 당첨 번호 문자열을 입력받는다.
    - [x] `보너스 번호를 입력해 주세요.`의 형식으로 안내 메시지를 출력한다.
    - [x] 사용자로부터 보너스 번호 문자열을 입력받는다.
    - [x] `당첨 통계\n---`의 형식으로 안내 메시지를 출력한다.
    - [x] 아래의 형식으로 로또 결과를 출력한다.
        - `3개 일치 (5,000원) - n1개`
        - `4개 일치 (50,000원) - n2개`
        - `5개 일치 (1,500,000원) - n3개`
        - `5개 일치, 보너스 볼 일치 (30,000,000원) - n4개`
        - `6개 일치 (2,000,000,000원) - n5개`
    - [x] `총 수익률은 f%입니다.`의 형식으로 수익률을 출력한다.

- ### 핵심 기능 (문자열 분리 + 무작위 값 생성 + 로또 발매/집계)
    - [x] 사용자의 구입 금액으로 가능한 로또 개수를 계산한다.
    - [x] 각 로또별로 1~45의 숫자 중 중복되지 않는 무작위 수 6개를 선택한다.
        - 로또 번호는 오름차순으로 정렬한다.
    - [x] 입력받은 당첨 번호들을 쉼표(,)기준으로 분리한다.
    - [x] 각 로또별로 당첨 여부를 확인하여, 등수별 당첨 개수를 집계한다.
        - 일반 번호 중 일치하는 개수를 카운트한다.
        - 일반 번호의 일치 개수가 5개인 경우, 보너스 번호 일치 여부를 추가 확인한다.
    - [x] 사용자의 구입 금액과 총 당첨 금액을 비교하여 수익률을 계산한다.
        - 수익률은 소수점 둘째 자리에서 반올림한다.

- ### 세부 설정
    - 로또의 가격은 1장 당 1,000원이다.
    - 구입 금액은 최소 5,000원, 최대 100,000원이다.
    - 구입 금액은 로또 가격인 1,000원으로 나누어 떨어져야 한다.
    - 당첨 번호를 입력받을 때 번호 앞뒤로 공백 문자열을 허용하지 않는다.
    - 당첨 기준과 금액은 아래과 같다.
        - 1등: 6개 번호 일치 / 2,000,000,000원
        - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
        - 3등: 5개 번호 일치 / 1,500,000원
        - 4등: 4개 번호 일치 / 50,000원
        - 5등: 3개 번호 일치 / 5,000원

- ### 예외 상황
    - 잘못된 입력은 예외(`IllegalArgumentException`)를 발생시킨다.
    - `[ERROR] {상세 내용}`의 형식으로 에러 메시지를 출력한다.
    - 해당 부분부터 사용자에게 재입력받는다.
        - 구입 금액 관련
            - [x] 빈 문자열 또는 공백 문자열인 경우  (ex. `""`, `" "`)
            - [x] 정수가 아닌 값인 경우  (ex. `A` / `0.1`)
            - [x] 최소/최대 범위를 벗어난 경우  (ex. `0`, `100,000`)
            - [x] 로또 가격으로 나누어 떨어지지 않는 경우  (ex. `2,500`)
        - 당첨 번호 관련
            - [x] 빈 문자열 또는 공백 문자열인 경우  (ex. `""`, `" "`)
            - [x] 번호 앞뒤에 공백이 포함된 경우  (ex. `1 , 2 , 3,...`)
            - [x] 정수가 아닌 값이 포함된 경우  (ex. `1,A,3,...`)
            - [ ] 6개의 번호를 입력하지 않은 경우
            - [ ] 로또 번호 범위(1~45)를 벗어난 경우  (ex. `50,...`)
            - [ ] 당첨 번호끼리 중복되는 경우  (ex. `1,1,...`)
        - 보너스 번호 관련
            - [x] 빈 문자열 또는 공백 문자열인 경우  (ex. `""`, `" "`)  
            - [x] 정수가 아닌 값인 경우  (ex. `A` / `0.1`)
            - [ ] 로또 번호 범위(1~45)를 벗어난 경우  (ex. `0`, `50`)
            - [ ] 당첨 번호와 중복되는 경우
